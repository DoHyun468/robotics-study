# RT-2 (2023)

*웹 지식을 로봇 제어로 — VLA라는 이름을 만든 논문*

Brohan, Brown 외 (Google DeepMind), *RT-2: Vision-Language-Action Models Transfer Web Knowledge to Robotic Control*, 2023 (arXiv 2307.15818). 카테고리 개요는 [VLA 리뷰 허브](vla.md), 우리가 직접 돌려본 후속작은 [OpenVLA](openvla.md), 실습 기록 전체는 [VLA 실습 페이지](../vla.md).

이 논문은 문헌만 리뷰했다 — 우리가 직접 실행하지 않았다. 가중치가 비공개라 재현 자체가 불가능하다(아래 참고).

## 한 줄 요약

> **PaLI-X(5B/55B)·PaLM-E(12B)** 같은 대형 VLM을 웹 VQA·캡셔닝 데이터와 로봇 시연 데이터에 **동시에(co-fine-tune)** 학습시켜, action을 **텍스트 토큰처럼** 뱉게 만든 모델. 웹 사전학습에서 온 "개념 일반화"가 그대로 로봇 제어로 전이되어, 학습 때 본 적 없는 물체·지시문·추론 태스크에서 성공률이 크게 뛰었다. 다만 **가중치는 끝까지 공개되지 않았다** — 이 자리를 나중에 [OpenVLA](openvla.md)가 메운다.

---

## 1. 문제 — 로봇 정책은 왜 "웹을 모르나"

RT-1 같은 이전 세대 로봇 정책은 로봇 시연 데이터로만 학습된다. 이 데이터는 인터넷 텍스트·이미지에 비하면 양도 적고 다양성도 낮다. 그 결과 로봇 정책은 학습 분포를 벗어난 물체나 지시문을 만나면 쉽게 무너진다 — "빨간 캔을 집어라"는 배웠어도 "마이클 조던 그림 위에 캔을 올려라" 같은, 로봇 데이터엔 없던 개념(사람 이름, 기호, 상대적 크기 비교)은 다룰 수 없다.

반면 VLM은 웹 스케일 이미지-텍스트 데이터로 이미 그런 개념들을 알고 있다. RT-2의 질문은 단순하다: **VLM에게 "이미지+질문→답변" 대신 "이미지+지시문→action"을 시키면, VLM이 가진 웹 지식이 로봇 제어로 전이되는가?**

## 2. 방법

### 2.1 Co-fine-tuning — 잊지 않으면서 로봇을 가르치기

로봇 시연만으로 파인튜닝하면 VLM이 원래 갖고 있던 일반화 능력을 잊어버린다(catastrophic forgetting). RT-2는 그래서 **로봇 궤적 데이터**와 **웹 VQA/캡셔닝 데이터(WebLI, 필터링 후 약 10억 쌍 규모)**를 **같은 배치 안에 섞어** 학습한다. 로봇 데이터가 minibatch의 약 50~66%를 차지하도록 업샘플링해 균형을 맞춘다(원문 기준).

### 2.2 Action-as-text — RT-1의 이산화 방식을 VLM에 얹기

$$
\text{이미지 } o_t,\ \text{지시문 } \ell \;\longrightarrow\; \text{VLM(PaLI-X/PaLM-E)} \;\longrightarrow\; \text{action 텍스트 토큰}
$$

RT-1에서 쓰던 방식을 그대로 계승한다 — 연속 action(위치·회전 변화량, 그리퍼, 로봇 베이스 이동 등)을 차원별 256-bin으로 이산화하고, 언어 토크나이저에서 **가장 안 쓰이는 토큰들을 덮어써서** 어휘에 편입시킨다. 이렇게 하면 action 예측이 VLM 입장에서는 그냥 "다음 텍스트 토큰 예측"이 되어, 별도 action head 없이 기존 VLM 학습 파이프라인을 그대로 쓸 수 있다. (뒤에 나온 [OpenVLA](openvla.md)의 action 토큰화가 사실상 이 방식을 그대로 물려받은 것이다.)

### 2.3 Chain-of-thought 변형

일부 실험에서는 action 토큰 앞에 자연어로 된 "Plan: ..." 단계를 끼워 넣어 다단계 추론을 유도한다(예: "먼저 봉투를 열어야 한다 → 그다음 사과를 집는다"). action만 바로 뱉는 것보다 복잡한 지시문 이행에 도움이 됐다고 보고한다.

### 2.4 백본과 스케일

- **PaLI-X**: 5B, **55B** 두 크기.
- **PaLM-E**: 12B.
- 55B 모델은 온보드가 아니라 **멀티-TPU 클라우드 서빙**으로 추론하며, 이 때문에 제어 주파수가 **1~3Hz**로 낮다(작은 모델은 ~5Hz). 저주파 제어라는 한계가 스케일의 대가로 명시적으로 드러난 지점.

## 3. 결과

- **미학습 시나리오 일반화**: RT-1의 32% → RT-2 평균 **62%**로 거의 2배(원문). 두 백본 모두 평균 62%를 냈지만 세부는 갈린다 — PaLI-X-55B는 미학습 **환경**(63%)에, PaLM-E-12B는 미학습 **물체**(76%)·**배경**(71%)에 더 강했다.
- **학습 태스크 성능은 유지**: PaLI-X-55B 91%, PaLM-E-12B 93% — RT-1의 92%와 대등해, 일반화를 얻는 대신 기존 성능을 잃지 않았다.
- **창발(emergent) 능력**: 기호 이해("숫자 3 위에 놓아라"), 의미적 추론("가장 작은 것을 집어라", "이것과 가장 가까운 것"), 사람 인식처럼 로봇 데이터에 전혀 없던 태스크 범주에서 최고 베이스라인(RT-1, VC-1) 대비 **3배 이상**의 평균 성공률(원문).
- **RT-2-X**: 후속 Open X-Embodiment 논문(arXiv 2310.08864, 별도 저자군)에서 22개 로봇·100만+ 궤적으로 다시 학습한 55B 변형. 같은 emergent-skill 평가에서 RT-2(55B) 27.3% 대비 **75.8%**로 약 3배 — [OpenVLA](openvla.md)가 비교 대상으로 삼은 것이 바로 이 RT-2-X다. RT-2 원 논문과 RT-2-X는 데이터·학습이 다른 별개 체크포인트라는 점은 구분해 둘 필요가 있다.
- **가중치·코드 비공개**: 논문·프로젝트 페이지만 존재하고, RT-2/RT-2-X 모델 가중치는 공개된 적이 없다. 재현 가능한 유일한 산출물은 Open X-Embodiment **데이터셋** 쪽이다.

## 4. 내 실습 연결

- 이 논문은 우리가 직접 돌린 게 없다 — **가중치가 없으니 돌릴 방법이 없다**. 대신 우리가 실제로 재현·파인튜닝까지 진행한 [OpenVLA](openvla.md)가 "이 자리를 메우려 한" 논문이라는 맥락으로 읽었다.
- 대비가 뚜렷하다: RT-2-X는 **55B, 클라우드 멀티-TPU 추론, 비공개**. OpenVLA는 **7B(1/7 규모), 단일 GPU, 완전 오픈 가중치**로 BridgeData V2에서 RT-2-X를 앞섰다(원문 기준 +16.5%p). 우리가 LIBERO 4-suite에서 직접 낸 수치(spatial 80% / object 85% / goal 85% / long 45%, 논문 대비 패턴 정합)는 "닫힌 55B"가 아니라 "연 7B" 쪽 계보에서 나온 결과다.
- action-as-text 설계(§2.2)는 OpenVLA에서 우리가 직접 다룬 256-bin 이산화·norm stats와 정확히 같은 아이디어의 원조다. OpenVLA 리뷰에서 겪은 "undertrain으로 LIBERO-Spatial 0%" 디버깅도 결국 RT-2가 처음 깐 이 action 토큰화 위에서 벌어진 일이다.
- 스케일 대 개방성이라는 축은 우리 [VLA 리뷰 허브](vla.md)의 "LIBERO에선 7B의 파라미터 이점이 거의 안 드러난다"는 관찰과도 맞닿는다 — RT-2가 보여준 "크면 창발한다"는 서사와, OpenVLA가 보여준 "작아도 오픈이면 접근 가능한 벤치에서 이긴다"는 서사가 같은 계열 안에서 충돌한다.

## 5. 한 줄 평 / 한계

**한 줄 평.** VLA라는 발상 자체를 증명한 논문. "웹에서 배운 개념이 로봇 action으로 전이된다"는 창발 결과(3배)는 이 분야 전체의 출발점이 됐지만, 정작 그 증거는 **비공개 55B 모델 + 클라우드 추론**이라는 형태로만 존재해 커뮤니티가 직접 검증하거나 재사용할 수 없었다.

**한계.**
- **완전 비공개**: 가중치·학습 코드·체크포인트 전부 미공개. 결과를 믿는 것과 직접 확인하는 것 사이에 메울 수 없는 간극이 있다 — OpenVLA가 존재하는 이유이기도 하다.
- **추론 비용**: 55B를 멀티-TPU 클라우드로 서빙해야 1~3Hz — 온보드 저지연 제어와는 거리가 멀다. 실사용을 염두에 둔 설계라기보다는 "일반화가 스케일에서 나온다"는 가설 검증에 가깝다.
- **RT-2와 RT-2-X 혼동 주의**: 커뮤니티에서 흔히 "RT-2"로 뭉뚱그려 인용되지만, OpenVLA 등이 베이스라인으로 삼은 55B 수치는 대개 별도 논문의 RT-2-X다. 두 체크포인트의 학습 데이터·성능은 다르다.
- **평가 규모**: emergent-skill 평가 태스크 수와 평가 환경이 상대적으로 작은 커스텀 셋이라(원문), 일반화 주장이 정확히 얼마나 넓게 성립하는지는 미확인.
