# GameNGen (2024) — 확산 모델로 만든 실시간 DOOM 게임엔진

작성: world-models 심화 트랙 · 원문 기준
- Valevski, Leviathan, Arar, Fruchter (Google), *Diffusion Models Are Real-Time Game Engines*, 2024 (arXiv 2408.14837).

같은 갈래: [DIAMOND](diamond.md) · [Genie](genie.md) · [Cosmos](cosmos.md) · [생성·영상형 개요로 돌아가기](index.md)

**생성·영상형 world model**은 관측(픽셀/토큰)을 확산·자기회귀 등으로 **직접 생성**해 "플레이 가능한 세계"를 만드는 계열이다. Dreamer/MuZero처럼 제어를 위한 컴팩트 잠재를 배우는 게 목적이 아니라, **관측 자체의 생성 충실도**가 목표다. GameNGen은 이 갈래에서 "신경망이 게임 엔진 그 자체를 대체할 수 있는가"라는 질문에 가장 직접적으로 답한 사례다.

---

## 1. 문제

world model을 극한까지 밀면 결국 **환경 그 자체를 신경망으로 대체**할 수 있는가라는 질문에 닿는다. 이때 두 난점을 마주한다.

1. **장기 일관성**: 프레임을 계속 자기회귀적으로 생성하면 상태가 표류(drift)하고 게임 로직·기하가 깨진다.
2. **정밀 제어·행동 조건화**: 사용자 입력(키 조작)을 정확히 반영하며 인과적으로 굴러가야 한다.

GameNGen은 이 둘을 "행동 조건 확산 모델 + 노이즈 증강"으로 정면 공략한다.

## 2. 방법

- **아이디어**: 신경망(확산)이 **게임 엔진을 대체** — 행동 입력을 받아 다음 프레임을 실시간 생성. 대상은 DOOM.
- **파이프라인**: (a) RL 에이전트로 대량 플레이 데이터 수집 → (b) 그 데이터로 **행동 조건 확산 모델** 학습 → (c) 프레임을 자기회귀적으로 생성하며 플레이. **단일 TPU에서 20 FPS** 실시간 구동.
- **장기 표류 대응**: 생성 프레임에 **노이즈 증강(conditioning augmentation)**을 넣어 자기회귀 롤아웃의 오차 누적을 완화.

## 3. 결과 (원문)

- 다음 프레임 예측 **PSNR 29.4**(손실 JPEG 수준).
- **사람 평가자가 5분 자기회귀 생성 후에도 실게임과 구분을 랜덤보다 약간 나은 수준으로만** 함.
- 의의: "충분한 데이터 + 확산이면 특정 게임의 **동역학+렌더링을 통째로** 신경망이 흉내낼 수 있다"의 실증.

## 4. 스터디와의 개념적 연결

- 트랙 프레이밍 그대로: "생성·영상형 = 화려하나 제어 미흡 → 로봇엔 sim/데이터 생성 용도가 먼저." GameNGen은 화질·실시간성의 상한을 보여주는 사례이되, 대상이 DOOM이라는 닫힌 이산 행동 게임이라 로봇의 연속·고정밀 제어로 바로 옮기긴 어렵다.
- 데이터 파이프라인 관점에서, RL 에이전트로 대량 플레이를 수집해 확산 모델을 학습시키는 이 구조 자체가 "합성 데이터로 사전학습"이라는 이 사이트의 문제의식([perception](../perception.md))과 같은 축이다.

## 5. 한 줄 평·한계

**한 줄 평.** "충분한 데이터 + 확산 모델이면 게임 엔진 자체를 신경망으로 대체할 수 있다"를 실시간 성능(20 FPS)으로 입증한 사례.

**한계.**
- **장기 표류**: 노이즈 증강으로 완화하지만 근본 해결은 아니다 — 플레이가 길어지면 결국 상태가 어긋난다.
- **연산 비용**: 실시간 20 FPS를 위해 TPU급 추론 자원이 필요 — 저사양·실시간 로봇 루프엔 그대로 부담이 된다.
- **평가 범위**: 대상이 DOOM 한 게임이라, 이 결과가 임의의 동역학·물리로 일반화되는지는 별개 문제.
