# VLA 계보 지도 (상설 문서 — 아카이빙 봇이 지속 갱신)

최종 갱신: 2026-09-07. 목적: "OpenVLA 이후 50개는 나왔는데"(마음AI 기출)류 질문에 **계보 구조로 답하기 위한 지도**. 전부 외울 필요 없음 — §1의 구조와 각 계열 대표 1~2개면 면접 방어 충분.

---

## §1. 왜 이렇게 많이 나오나 — 축이 3개라 조합이 폭발한다 (면접 첫 문장)

> "VLA는 설계 축이 세 개입니다 — ① 액션을 어떻게 표현하나(이산 토큰 / 디퓨전·플로우 연속) ② 백본을 어떻게 쓰나(단일 VLM / 시스템1·2 분리) ③ 데이터를 어디서 얻나(공개 OXE / 자체 수집 / 시뮬). 이 조합마다 모델이 나오니 수십 개가 되는 것이고, 저는 개별 모델보다 이 축으로 흐름을 추적합니다."

## §2. 시대 구분 (타임라인)

| 시기 | 사건 | 의미 |
|---|---|---|
| 2022 | **RT-1** (Google) | 로봇 데이터 13만 에피소드로 트랜스포머 정책 — VLA 전사(前史) |
| 2023 | **RT-2** (Google DeepMind) | 웹 사전학습 VLM에 액션을 텍스트 토큰으로 — "VLA"라는 이름의 시작 |
| 2023 | **RT-X / OXE** | 크로스 임바디먼트 공개 데이터셋(로봇 20여 종) — 이후 모든 공개 VLA의 토대 |
| 2024 상 | **Octo** | OXE 기반 공개 generalist, 디퓨전 액션 헤드 |
| 2024 중 | **OpenVLA** (7B) | 공개 가중치+파인튜닝 레시피의 표준 기준선 — Prismatic VLM(SigLIP+DINOv2+Llama2), 256구간 이산화 ← **내 실험 기준선** |
| 2024 말 | **π0** (Physical Intelligence) | flow matching 연속 액션 청크 50@50Hz — 이산화 탈피의 전환점 (아카이브 1호) |
| 2024 말 | RDT-1B, CogACT | 디퓨전 액션 헤드 계열 확산 |
| 2025 초 | **π0-FAST** | 연속 액션을 다시 토큰화(FAST 토크나이저 — DCT 기반 압축)해 자기회귀로도 고주파 — 두 진영의 수렴 |
| 2025 초 | **Helix** (Figure) | 시스템1(빠른 제어)+시스템2(VLM 추론) 이중 구조, 휴머노이드 상용 지향 |
| 2025 봄 | **GR00T N1** (NVIDIA) | 이중 시스템 구조의 공개판 + 시뮬 합성 데이터 대량 활용 → N1.5로 갱신 |
| 2025 봄 | **Gemini Robotics** (DeepMind) | 프론티어 VLM 직결 VLA + ER(구현 추론) 분리 |
| 2025 | **OpenVLA-OFT** | 기존 모델 재학습 아닌 **파인튜닝 레시피 개선**(병렬 디코딩·연속 액션·L1)으로 대폭 향상 — "레시피도 연구다" |
| 2025 | SpatialVLA, SmolVLA(HF 소형), π0.5(개방 환경 일반화), MolmoAct 등 | 공간 표현 주입 / 엣지 경량화 / 일반화 확장 |
| 2026 | ABot-M0, StarVLA 등 신작 지속 + 국내(WoRV RFM, RLWRLD 등) | 도메인 특화·경량화·RL 사후학습 결합이 전선 |

## §3. 계열별 지도 (이걸로 답하기)

### A. 이산화 자기회귀 계열 — "액션 = 텍스트 토큰"
- RT-2 → **OpenVLA**(256빈/자유도) → SpatialVLA(3D 위치 인코딩 주입) → **π0-FAST**(FAST 토크나이저로 압축 이산화)
- 장: LLM 인프라 그대로, 다봉 분포 분류로 처리 / 단: 양자화 정밀도·자기회귀 속도
- CANVAS(웨이포인트 K-means 이산화)도 이 사상의 내비 특화판

### B. 디퓨전/플로우 연속 액션 계열 — "액션 청크를 생성"
- Octo(디퓨전 헤드) → RDT-1B(1B 디퓨전 트랜스포머) → CogACT(VLM+디퓨전 액션 모듈 분리) → **π0(flow matching — 계열 정점)** → GR00T N1(플로우 계열 채택)
- 장: 연속 정밀도·고주파(50Hz)·청크 단위 시간 일관성 / 단: 적분 스텝 추론 비용(π0는 10스텝으로 완화)

### C. 이중 시스템(System 1/2) 계열 — "생각은 느리게, 제어는 빠르게"
- **Helix**(Figure): S2 VLM(7~9Hz) + S1 제어 정책(200Hz) / **GR00T N1**: 같은 구조의 공개판 / Gemini Robotics: 프론티어 VLM + 로컬 실행 모델
- 문제의식: VLM 추론 지연 vs 제어 주파수의 불일치 — π0의 action expert 분리도 같은 문제의 다른 해법

### D. 경량/엣지 계열
- TinyVLA, **SmolVLA**(HuggingFace, ~0.5B급), CANVAS-S(0.7B) — 온보드(Orin급) 실시간이 목표. "작은 모델이 실기에서 더 낫기도 하다"(CANVAS-S 69% > L 63%)

### E. 학습 레시피/평가 계열 (모델이 아니라 방법)
- **OpenVLA-OFT**(파인튜닝 레시피), π0.5(이종 데이터 co-training으로 개방 환경 일반화), RL 사후학습 흐름(BC 상한 돌파) — 마음AI JD "사전학습+RL 파이프라인"이 이 전선

## §4. 면접 방어 세트

**Q. "OpenVLA 이후 뭐가 나왔는지 아나?"**
> §1 축 문장 → "이산화 쪽은 SpatialVLA·π0-FAST로, 연속 쪽은 π0가 flow matching으로 정점을 찍고 GR00T N1이 공개판으로 이었고, Figure Helix처럼 시스템1·2를 나누는 흐름이 상용 휴머노이드 쪽 표준이 되고 있습니다. 레시피 연구로는 OpenVLA-OFT가 모델 교체 없이 파인튜닝만으로 큰 폭을 올렸고요."

**Q. "그럼 지금 뭘 쓸 건가?"**
> "목적에 따라 다릅니다 — 공정 비교 기준선이면 여전히 OpenVLA(재현성), 실기 고주파 조작이면 π0 계열이나 GR00T N1(공개 가중치), 엣지면 SmolVLA급. 저는 고정 하네스를 갖고 있어서 어떤 계열이든 같은 조건으로 실측해 고르는 쪽입니다."

**Q. "50개나 되는 걸 어떻게 따라가나?"**
> "개별 모델이 아니라 축의 이동을 봅니다 — 액션 표현이 이산→연속→수렴으로, 구조가 단일→이중 시스템으로, 병목이 모델→데이터·평가로 이동해온 흐름이요. 새 모델은 이 지도 위 어디에 놓이는지만 확인하면 됩니다." (+ 격일 아카이빙 습관 언급 가능)
